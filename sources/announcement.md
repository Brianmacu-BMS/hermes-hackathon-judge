The Hermes Agent Plugin Hackathon starts now! It runs for 7 days, with $20,000 in cash prizes and more. Plugins are the most powerful way to extend Hermes Agent, and we want this hackathon to show what they can do. A plugin can change anything from the model Hermes runs on, where it stores its memory, where it runs commands, which messaging apps it works in and what Hermes Desktop shows. Plugins in the marketplace already let Hermes do things like control a phone or turn a photo into a printable 3D model. Every kind of plugin is eligible, so build whatever functionality you want Hermes to have. We'll list accepted entries in the new Hermes Marketplace, where every Hermes user can install them. Prizes 1st: $10,000 + neon sign + merch + $1,000 creds 2nd: $5,000 + neon sign + merch + $1,000 creds 3rd: $2,500 + neon sign + merch + $1,000 creds 4th: $1,500 + merch + $500 creds 5th: $1,000 + merch + $500 creds Runners up (x5): merch + $250 creds Submissions are due 5PM EST on Nov 11th. To enter: 1. Open a pull request that adds your plugin to the Hermes plugin catalog: [hermes-agent.nousresearch.com/docs/developer…](https://t.co/mXvYukJ0mZ) 2. Post a demo video on X and tag [@NousResearch](/NousResearch) 3. Submit both links through the form: [form.typeform.com/to/FwJLvOln](https://t.co/jlduHHW3dr) Your entry is the plugin itself. Judges score it on usefulness, reliability, polish and creativity, and they favor plugins that do more than a prompt or a skill could. Keep the demo under 90 seconds and show the plugin working. The developer guide shows how to build and test a plugin: [hermes-agent.nousresearch.com/docs/developer…](https://t.co/FVGjSgjNoV) When submissions close, we'll open a thread for every entry in the Nous Research Discord, so you can browse all the plugins and talk to the people who built them. You can submit the form as soon as your pull request is open. The catalog checks run once a maintainer starts them, and we review entries every few days. If you have any questions stop by the Nous Research Discord: [discord.gg/nousresearch](https://t.co/qxek9haYeb) GLHF!
